LIFE PLANNER ДЛЯ ANDROID — проект для облачной сборки APK

Внутри находится Android-проект и текущий index.html. Приложение открывает HTML локально во встроенном Android WebView:
- основные разделы могут работать без интернета;
- данные хранятся локально в приложении;
- JavaScript, localStorage и выбор изображений включены;
- приложение запускается отдельно со своей иконки.

КАК СОБРАТЬ APK ЧЕРЕЗ GITHUB ACTIONS (без Android Studio и SDK на ноутбуке)

1. Войди или зарегистрируйся на github.com.
2. Создай новый репозиторий (New repository). Можно назвать LifePlannerAndroid. Для первого раза выбери Public, чтобы не упираться в ограничения GitHub Actions для приватных репозиториев.
3. Распакуй этот ZIP на компьютере.
4. На странице репозитория нажми Add file → Upload files.
5. Перетащи ВСЁ содержимое распакованной папки проекта, включая скрытую папку .github, в окно загрузки. Важно: загружай содержимое папки, а не сам ZIP.
6. Нажми Commit changes.
7. Открой вкладку Actions. Выбери workflow “Build Life Planner APK”.
8. Нажми Run workflow → Run workflow.
9. Дождись зелёной галочки. Открой завершённый запуск и внизу страницы найди Artifacts.
10. Скачай LifePlanner-debug-apk.zip и распакуй его. Внутри будет app-debug.apk.
11. Перенеси APK на Android-телефон и установи. Если Android спросит разрешение на установку из этого источника, разреши его для приложения, через которое открываешь APK.

Если папка .github не отображается при выборе файлов, включи показ скрытых элементов в Проводнике Windows: Вид → Показать → Скрытые элементы.

ВАЖНО:
- Это конфигурация облачной сборки, а не уже собранный APK.
- Для запуска сборки GitHub Actions должен быть доступен из браузера; если github.com не открывается, этот путь может не подойти.
- При сборке GitHub Actions скачает Android SDK на свой облачный компьютер, а не на твой ноутбук.
- Приложение использует локальные файлы внутри APK. Сетевые возможности самого планировщика не требуются для основных функций, но отдельные функции устройства (например, голосовой движок) могут иметь свои требования.
- Не удаляй приложение после начала использования без экспорта/резервной копии данных: данные хранятся локально в приложении.
